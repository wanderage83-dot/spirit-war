# 청룡 전투 필드 HD 그림

## 요청 8 · 절벽 면 조각 전달

`qing-cliff-face.png`를 추가했다. 1024×512 투명 PNG, 불투명 색 40개, 4×4 도트 격자, 알파 0/255다. cliff-top을 참고로 사용자 프롬프트와 공통 문장으로 생성하고 두 차례 각도/평행 보정을 요청했다. BOX 축소·40색 제한·nearest 4배 확대를 적용했으며 임의의 전단/세로 늘리기는 하지 않았다. 실제 바위 면 세로 두께의 중앙값은 약 159px다.

- 알파 범위: `(328,84)~(700,476)`(우측·아래 exclusive). 이 조각을 35도에 가깝게 512px 높이 안에 넣으려면 가로 길이를 짧게 해야 해서 좌우 투명 여백이 크다. 캔버스 양 끝을 이어 붙이는 방식은 맞지 않는다.
- 중앙 x=402~643의 아래 윤곽은 `y ≈ -0.64220*x + 696.201`, 약 **32.71°**다. 위 윤곽은 `y ≈ -0.71888*x + 576.010`이다. 이끼·양치·돌 장식까지 포함한 근사 측정값이며 실제 연결점은 양 끝의 바위 면을 보고 정한다.
- **목표 0.707/35.26°와 아래 윤곽이 다르고 오른쪽 끝이 조금 두꺼워진다.** 실제 연결 전에 각도 보정과 끝부분 클리핑/겹침 정렬이 필요하다. 단순 평행 이동만으로 위·아래가 모두 완벽히 이어지는 그림은 아니며 무보정 접합 완료로 취급하지 않는다. 위·아래 경계가 정확히 맞아야 한다면 추가 그림 수정이 필요하다.
- 형식·알파·색 수·4×4 도트 격자와 브라우저 디코딩 검사를 통과했다. **게임 연결·모바일 실기·연속 접합 검수는 아직**이다. 기존 그림과 코드는 그대로 유지했다. gorge·ridge·canopy는 이번에 만들지 않았다.

## 요청 8 · 절벽 위 고원 타일 전달

`qing-cliff-top.png` 한 장을 추가했다. 1024×1024 불투명 RGB PNG, 40색, 4×4 도트 격자다. 요청 프롬프트와 공통 문장을 사용하고 `qing-ground.png`·`qing-hill.png`를 화풍 참고로 첨부해 생성했다. 기존 저지대보다 옅고 마른 풀, 평평하게 드러난 회색 판석·지의류·작은 들풀이 있는 고원 윗면이며 절벽 옆면은 포함하지 않는다.

바닥 원본을 BOX로 축소해 40색으로 정리한 뒤 nearest 4배 확대했다. 규격·알파·색 수·도트 격자와 브라우저 디코딩을 확인하고 2×2 반복 미리보기를 검수했다. 실제 전장 투영에서 반복 경계가 보이는지는 연결 후 확인한다. **게임 연결은 하지 않았다.** 기존 그림·코드는 그대로며 요청 8의 나머지 4그림도 아직이다. Claude가 `HD_ART_FILES`와 pass/canyon의 고원 윗면에 연결한다.

ART_REQUESTS.md 요청 6의 공통 HD 그림이다. 1차~3차 29파일을 Claude가 `9180718`까지 버들골에 연결했다. 이후 사용자 결정에 따라 귀왕을 제외한 청룡·현무·주작·백호의 12지역에서 이 그림들을 함께 쓴다. 귀왕성·혼령곡·망자벌은 기존 잿빛 그림을 유지한다. 진영별 추가 제작 계획은 보류한다. 아래 과거 전달 기록의 「연결 전」과 「다음 진영 제작」은 각 제작 당시 상태다.

공통화는 `hdOn()`·`pixelColors()`·`mapTheme()`의 전장 그림 선택에만 적용한다. 지역 데이터의 진영·이름과 길·강·협곡·숲·고지 배치는 바꾸지 않는다. 다리 맵의 기존 돌 둑 띠는 `qing-bank.png`로 대체했다. 귀왕군 적 거점/귀문은 공통 전장 안에서도 전용 PNG를 사용한다. `tests/hd-common.cjs`가 적용 지역·귀왕 예외·충돌/경로 보존·물가 그리기·세 화면 규격을 검사한다.

## 배치 정보

- 바닥 두 장은 정사각형을 바로 위에서 본 질감이다. 그림 자체를 미리 마름모로 자르지 않았다. 기존 전장 바닥 투영으로 눕혀서 사용한다.
- 대숲 자르기: `(x,y,w,h)`가 각각 `(0,0,512,512)`, `(512,0,512,512)`, `(1024,0,512,512)`, `(1536,0,512,512)`다. 각 칸의 줄기 밑끝은 y=496 직전이며 아래 투명 여백은 16px다.
- 집과 성벽 모서리 밑끝은 y=744 직전(아래 24px 여백), 성벽 직선 조각 최저점은 y=496 직전(아래 16px 여백)이다. 캔버스 여백을 유지한 채 배치하고 임의로 다시 꽉 잘라내지 않는다.
- 그림 확대/축소에는 nearest 보간을 사용한다. 병사 화면 높이 40px 기준으로 집은 약 240~320px, 대숲 한 덩어리는 약 120~200px 높이를 시험 시작점으로 삼고 실제 버들골 화면에 맞춘다. 그림의 표시 크기와 기존 충돌/길찾기 크기는 별개다.
- 성벽은 직선 조각과 바깥 모서리 조각이 있다. 반대 방향 직선 그림은 아직 없다. 게임 투영 기준은 **기울기 0.707(35.26°)**이며, 이전 2:1 기준은 잘못된 설명이다. 끝점 정렬·이어 붙이기·전장과의 정합은 새 그림을 버들골에 연결할 때 다시 확인한다.

## 2차 ①~③ 측정·인계 (2026-11-07)

- 기존 성벽 그림을 첨부해 다시 생성하고, 한 번 더 「더 가파르게, 35도」로 수정했다. 원본 비율을 유지한 채 캔버스에 맞췄으며 그림 전체를 기울이거나 세로로 늘리지는 않았다.
- **최종 성벽 아랫선 측정 기울기는 약 −0.6054(31.19°)**다. 기존 약 −0.3409보다 가팔라졌지만 목표 −0.707에는 못 미친다. 사용자가 허용한 대로 이 결과를 전달하며, 각도가 정확하다고 취급하지 않는다. 모서리도 새 직선 조각과의 접합을 실기에서 맞춰야 한다.
- 성벽 불투명 영역은 `(296,16)~(724,496)`, 모서리는 `(16,136)~(496,744)`다(우측/아래 좌표는 exclusive). 이 값은 잘라내기 범위이며 실제 벽의 연결점 좌표가 아니다.
- 성벽 중앙 구간 x=382~659의 알파 아래 윤곽을 선형 회귀하면 `y ≈ -0.60537*x + 702.932`다. 돌/풀 장식과 픽셀 계단이 있어 수동 연결점 측정을 대신하지 않는다.
- **기존 코드의 `HD_WALL={u0:176,u1:847,mid:[512,401],slope:.34}`는 옛 그림 기준**이다. 새 PNG에 그대로 맞는 값이 아니므로 Claude가 재측정해 갱신해야 한다. 이 작업에서는 게임 코드를 바꾸지 않았다.
- 새 길은 양옆 띠 없이 전체가 길 표면이다. 기존 코드가 쓰던 x=40~984 잘라내기도 Claude가 전체 타일 사용으로 바꿀 수 있다. 양옆 x=8~36 / 988~1016 띠의 평균 밝기를 중앙 x=128~896과 비교한 비율은 기존 0.875 / 0.903에서 새 그림 1.002 / 0.991로 개선됐다. 2×2 반복 미리보기로도 검수했다.
- 나머지 1차 바닥·집·대숲 파일은 변경하지 않았다. 수정·추가한 세 그림은 각 40색, 4×4 도트 격자, 두 소품은 이진 알파(0/255), 길은 전체 불투명이다.
- 새 세 PNG의 브라우저 로딩/디코딩과 규격 검사를 통과했다. `node tests/hd-terrain.cjs http://127.0.0.1:8802/`도 390×844·844×390·1280×800에서 통과했다(그림 로딩/기존 렌더 호출·충돌/경로 보존·다른 지역 미적용·화면 넘침 검사). 이 검사는 새 모서리 연결이나 성벽 기울기의 시각적 정합을 검증하지 않으며 기존 길 잘라내기도 유지된 상태다.

## 검수와 다음 작업

파일별 크기·색 수·도트 격자·알파·소품 여백과 대숲 네 칸을 검사했다. 바닥 2×2 반복 미리보기를 시각 검수하고 브라우저 PNG 로딩/디코딩을 확인했다. 새 그림의 각도·접합·전장 실기 검수를 통과했다는 뜻은 아니다.

위 ①~③ 인계는 제작 당시 기록이다. 이후 Claude가 `23e533f`에서 성벽 기울기 기준을 0.602로 바꾸고, 모서리 4곳과 전체 길 타일을 버들골에 연결했다. 그 6파일과 게임 코드는 이번 ④~⑦ 제작에서 변경하지 않았다. 다음은 새 17파일의 버들골 연결과 실제 표시 크기·각도·접합 확인이다. 그림이 없는 항목은 기존 그림을 유지한다. 천하도·대화 무대·인물·병사·판정·충돌·길찾기는 이번 제작 범위에 포함하지 않는다.

### 분할과 발밑

- 정확한 크기·각 칸의 알파 범위·밑끝·측정값은 [qing-second-manifest.json](qing-second-manifest.json)에 있다. 좌표는 최종 PNG 기준이며 우측/아래는 exclusive다.
- 소품 세 시트는 각각 `(0,0,512,512)`·`(512,0,512,512)`·`(1024,0,512,512)`·`(1536,0,512,512)`로 자른다. 모든 칸의 최저점은 y=496 직전이고 아래 16px는 투명하다. 서로의 칸으로 넘어가지 않는다.
- 높이 768인 건물과 관문은 y=744 직전, 높이 1024인 본진과 망루는 y=992 직전, 높이 512인 목책은 y=496 직전까지 알파가 있다. 표시할 때 이 여백을 유지한다.
- `bottom_envelope_center_x_estimate`는 맨 아래 8px에서 불투명 픽셀의 x 중앙값을 잰 **참고값**이다. 나무 줄기 중심이나 건물의 월드 중심을 보장하지 않으며, 실제 배치 기준은 그림을 보고 맞춰야 한다.
- 시설은 돌로 된 일체형 훈련 단/기초가 포함된다. 주변 땅이나 투사 그림자는 포함하지 않았다. 바닥 텍스처는 게임에서 투영하며 소품은 이미 등각인 그림을 그대로 세운다.

### 관문·목책 각도

- 알파 아래 윤곽의 중앙 구간을 회귀한 관문은 `y ≈ -0.70078*x + 929.385`(x=315~741), **약 35.02°**다.
- 목책은 `y ≈ -0.68637*x + 729.552`(x=404~637), **약 34.46°**다. 목표 0.707/35.26°에 가깝지만 정확히 일치한다고 취급하지 않는다.
- 두 수치 모두 기둥·석축·풀이 섞인 아래 윤곽 측정이다. 실제 이어 붙일 끝점과 문 양옆 기둥 기준점을 Claude가 따로 재고 작은 전단/정렬 보정을 적용한다. 그림의 왼쪽/오른쪽 캔버스 끝을 연결점으로 쓰면 안 된다. 목책 반복 접합과 관문 연결은 아직 게임에서 검수하지 않았다.

### 검사 결과와 남은 확인

- 17파일의 크기, 불투명 색 40개, 4×4px 도트 격자, 바닥 전체 불투명, 소품 알파 0/255, 소품 네 칸과 여백 검사를 통과했다. 원본 생성물에서도 칸 경계/캔버스에 잘린 부분이 없는지 확인했다.
- 바닥 5종은 2×2 반복 미리보기로 검수했다. 양끝 픽셀이 수학적으로 동일한 타일은 아니며, 수면 물결과 돌 줄눈은 접합점에서 끊겨 보일 수 있다. 실제 투영·배율에서 이음새가 드러나면 해당 타일을 추가 수정한다. 휴대폰에서 완전한 무이음 검수를 마쳤다는 뜻은 아니다.
- Chromium에서 새 PNG 17파일 로딩/디코딩이 통과했다. 기존 `tests/hd-terrain.cjs`도 390×844·844×390·1280×800에서 통과했다(기존 6파일 렌더·충돌/경로 보존·다른 지역 미적용). **이 검사는 새 17파일이 게임에 연결되었거나 배치가 맞다는 뜻이 아니다.**
- 기존 PNG 6파일과 `index.html`은 작업 시작 HEAD(`23e533f`)와 바이트가 같다. 게임 코드·검사 코드·판정·충돌·길찾기는 수정하지 않았다. 새 파일을 로더와 실제 그리는 위치에 연결하고 모바일에서 확인하는 작업은 Claude가 이어서 한다.

### 제작과 배치

- 항목마다 기존 청룡 그림 1~2장(집·바닥·물·성벽)을 참고로 첨부했다. 요청한 영어 문장과 공통 문장을 사용하고, 규격 정리에 BOX 축소·40색 제한·nearest 4배 확대를 적용했다. 사람·병사·UI·읽을 수 있는 글자는 넣지 않았다. 부적의 추상 무늬는 장식이다.
- 물가 초안은 위쪽 육지/아래쪽 물이 나뉘어 반복에 맞지 않았다. 전체에 젖은 자갈과 얕은 물이 고르게 퍼지는 질감으로 다시 생성했다. 강변의 실제 윤곽은 게임의 마스크로 정하며 그림 안에 해안선을 고정하지 않았다.
- 귀문의 밝은 발광막은 제거했다. 문 안은 투명하고 기둥 안쪽에 옅은 보라색만 남겼다. 큰 빛 번짐·안개는 게임이 필요에 따라 처리한다.
- 세운 물체는 원본의 지붕·깃발·석축·사다리 끝이 잘리지 않았는지 확인했고, 비율을 유지해 캔버스 안에 배치했다. 자세한 좌표는 [qing-third-manifest.json](qing-third-manifest.json)에 있다.
- 적 거점 알파 범위는 `(20,16)~(1000,992)`, 귀문은 `(16,208)~(752,992)`, 봉화대는 `(56,16)~(456,744)`다(우측/아래 exclusive). 적 거점·귀문 밑에는 32px, 봉화대 밑에는 24px 투명 여백이 있다. 이 여백을 유지해 배치한다.
- 귀문은 가로로 넓은 원본 비율을 유지해 768px 폭 안에 넣었으므로 위쪽 여백이 크다. 세로로 늘리지 말고 알파 범위와 실제 두 기둥의 발 위치를 기준으로 표시 크기·기준점을 맞춘다.
- 바닥은 투영 전 정사각형 질감이다. 고지 그림에는 절벽/옆면이 없으며, 논의 모 간격과 물가 자갈 크기는 실제 전장 배율에서 확인한다. 바닥 세 장은 2×2 반복 미리보기로 검수했지만 양끝 픽셀이 수학적으로 같은 타일은 아니다. 실제 투영에서 이음새가 보이면 추가 수정한다.
