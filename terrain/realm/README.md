# 천하도 담채 지도

`atlas.webp`는 천하도 전용 풍경화 배경이다. 기존 천하도 바탕을 지리 참고로 첨부해 새로 생성했다. 설산·황토 산맥·대숲·버드나무·가을 들판은 담채와 먹선으로, 중앙 귀왕 영토는 먹빛 산등성이·금 간 땅·고사목·폐허·잿빛 안개·옅은 보라색 균열로 그렸다. 문자·군대·도로·성곽 UI는 그림에 넣지 않았다.

- 원본 비율을 유지한 1499×1049 불투명 WebP, 품질 93, 약 724KiB다. 전투 필드용 도트 그림과 별개이며 픽셀 격자/40색 변환은 하지 않았다.
- `loadRealmArt()`가 이미지를 비동기로 읽고 `buildRealmRaster()`의 바탕으로 쓴다. 지명·강·성벽·도로·교량·도시·군대·장 표지·선택 표시·소유권은 기존 코드가 위에 그린다.
- `rIdx`·`rAdj`·`rRoadPath`·`realmAt`·저장 데이터는 기존 지리를 그대로 사용한다. 그림 로딩에 실패하면 기존 코드 지도 바탕을 그린다.
- 담채의 명암이 보이도록 소유권 색 채움을 옅게 하고, 전체 보기의 캐릭터 무리는 조금 작게 표시했다. 국가 경계와 선택 지역 강조는 계속 보인다.
- `tests/realm-art.cjs`: 그림 유무에 따른 지리/인접/도로 동일, 기본 그림 복귀, 귀왕 영토의 어두운 명암, 점령 표시 갱신, 세 화면 규격에서 15지역 클릭, 실제 이미지 요청 실패 시 기본 지도 동작.
- `tests/map-portraits.cjs`: 모바일 세 규격의 전체 보기·터치 확대·자동/수동 카메라와 초상 표시 기존 검사 통과.

전투 지형·군대 수치·이야기·진행 저장 구조는 변경하지 않았다.
