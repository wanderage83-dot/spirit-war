# spirit-war
청룡전기 — 귀여운 동양 판타지 전술 게임. 마을 편성, 보급, 실시간 전투와 횟수제 작전 모드.

## 세계관 · 다음 봄의 값
나라를 구할수록, 군주는 자신을 잃는다.
- 세 법칙: 계절은 군주의 기억을 먹는다(봄=기쁨, 여름=사랑, 가을=성취, 겨울=슬픔). 왕관은 죽어서만 벗을 수 있으며 가장 진심으로 따르던 사람에게 이어진다. 마지막 증인을 잃은 군주는 검은 갑주를 입고 귀왕의 일부가 된다.
- 첫 도입 편지와 군주별 사연, 메뉴·천하 정세의 「기억의 서」. 계절을 넘길 때 바칠 기억을 직접 선택하며, 기록과 편지의 단서가 저장된다. 선택 전 취소하면 계절과 자원은 변하지 않는다.
- 현무·백호·주작 도성을 점령하면 군주를 기억하는 증언이 남는다. 귀왕성 함락 뒤 자기 기억을 바치기 / 함께 대가를 내기 / 계절을 멈추기의 결말 선택. 함께하는 결말은 세 도성의 증언이 필요하다.
- 기존 브라우저 저장을 유지하고 세계관 기록만 기본값으로 추가한다. 기존 진행 이전의 기억을 임의로 차감하지 않는다.

## 화면 크기 대응
- 실제 화면 높이에 맞춰 전장 크기를 자동 배분. 작은 화면의 전투 명령·충원·팝업은 스크롤로 끝까지 접근 가능하며 부대 카드는 가로 스와이프로 선택.
- 모바일 가로 화면은 천하도와 메뉴를 좌우 배치, 세로 화면은 위아래 배치. 노치·홈 표시줄 안전 영역 반영.

## 사방의 결전 (4방향 전장)
- 45° 회전·45° 고도의 아이소메트릭 전투 뷰 · 지형은 마름모 투영, 병사·수목·건물은 수직 표시 · 투영 깊이순 가림 처리
- 전장 면적 4배 확장(가로·세로 각 2배), 이동 속도·사거리·시야는 유지해 우회와 분산 운용 강화 · 최소 25% 축소로 넓은 전황 확인
- 장수 포함 6개 부대(숫자키 1~6), 기본 병사 90명(기존 60명의 1.5배) + 장수 1명. 백호·비룡 기병대를 각각 지휘해 양익 우회·예비대 운용. 병영은 1명 단위 편성, 전장 충원 상한 150명. 적 병력도 약 1.5배로 증가
- 4800×4800 정사각 전장 · 드래그/방향키로 상하좌우 이동 · 휠/핀치 확대 · 미니맵
- 귀왕군은 **북**(중앙 돌다리) · **서**(안개 대숲·여울) · **동**(바람 들판·나무다리) · **남**(남서 산길 배후 기습)에서 청룡관을 노린다
- 모든 부대는 바라보는 방향이 있다: 측면 공격 +20%, 배후 공격 +50%, 정면(±66°)의 적만 공격 가능
- 방패병은 정면 화살만 막고, 창진은 정면 돌격만 저지한다
- 진형 방향 ▲◀▶▼(PC: I/J/K/L)로 제자리 진형 전환, 땅을 누르면 이동 방향을 바라보며 진형
- 거점: 군량소(군량 +8/초) · 영맥(기력) · 봉화대(시야 확장, 적 동향 25초 전 경보)
- 전장의 안개: 아군 시야 밖의 적은 보이지 않으며, 대숲 속 적은 더 가까이 가야 보인다
- 패배: 장수 전사 또는 청룡관 함락 · 승리: 북쪽 귀왕성의 귀왕 처치
- 작전 모드: 전장을 최대 15초 멈추고 지시 · 30초마다 1회 충전, 최대 3회 보관(PC: E) · 일반 일시정지 중에는 명령 불가
- 전투 속도 75%, 피해량 하향으로 교전이 길어져 우회·진형 전환할 시간이 생김 · 정지한 방패·창 대열은 정면 피해 -20%
- 타격 효과: 피해 숫자(측면·배후·돌격 강조), 불꽃 파편, 넉백, 히트스톱, 피격 섬광
- 선택 부대: 금색 맥동 링·외곽 발광·부대 표지, 나머지 아군은 흐리게

## 사신의 천하 (정치·전략 화면)
- 동양 판타지 애니메이션풍 군주 얼굴 초상 5종: 청룡 군주·현무 학자 군주·백호 발명가 군주·주작 여왕·얼굴을 검은 갑주로 가린 귀왕. 천하 정세와 지역 상세 패널에 표시.
- 청룡국(동)·현무국(북)·백호국(서)·주작국(남)·귀왕군(중앙) 15개 지역의 수묵 담채 천하도
- 계절 단위 턴: 관리(장수) 1명당 계절마다 1회 명령 — 개간·상업·징병·위무·축성·출진/이동
- 한눈에 보는 진행: 처음 화면의 3단계 안내(지역 고르기 → 명령 → 계절 넘기기), 상단의 이번 계절 명령 패(일한 관리는 「用」 도장), 명령 가능한 아군 지역의 금색 점, 명령이 남은 채 계절을 넘기면 한 번 더 확인
- 명령 카드는 결과·비용·맡을 관리를 미리 보여 주고, 못 하는 이유도 표시 · 지역 상태는 막대와 숫자로
- 명령 효과: 지도 위 수치 상승·금빛 물결(내정), 兵 모으기(징병), 진군 점·격돌·「陷/敗」 도장(출진), 「禮/和/亂」 도장(외교), 계절 글자 전환과 자원 집계(계절 넘기기) · 출진 창에 열세~우세 승산 표시
- 외교: 예물·화친(8계절 불가침)·이간(2계절 내분) · 귀왕군과는 협상 불가
- 출진 시 직접 지휘(실시간 전투) 또는 자동 전투 · 적 침공 시 방어전도 선택
- 무작위 사건(풍년·역병·귀왕의 저주·인재 방문 등), 함락한 나라의 장수 등용
- 귀왕성 함락 시 마지막 계절의 대가를 선택하는 결말, 청룡성 함락 시 패배 · 진행 상황은 브라우저에 자동 저장
- 장수 충성도: 명령을 맡기면 +1, 놀리면 -2, 지역을 잃으면 크게 하락 · 포상(金100)으로 +15 · 적국 밀사 사건 · 충성 40 미만이면 병력을 이끌고 적국으로 넘어가거나, 20 미만이면 성을 바치는 반란
- 계절 날씨 전투: 봄 안개(시야 -30%) · 여름 장마(서쪽 여울 범람, 화살 -20%) · 가을 하늘(천고마비, 기병 +10%) · 겨울 결빙(강 전체를 건널 수 있음, 이동 -12%, 군량 소모 +30%)
- 도성 버들마을: 상태(병력·군량·기력·계절)와 건물별 명령(병영 편성·창고 보급·사당 축복·전장 정보)을 한 화면에 · 명령마다 1~2초 실행 효과(숫자 상승, 보급품 날아가기, 축복 빛, 出陣 붓글씨)
- 천하도: 동해·남해 해안선, 요동·산동 반도, 황하·장강, 호수, 섬, 만리장성이 있는 삼국지풍 지도
