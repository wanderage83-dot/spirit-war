각 병종의 아군 원본 1장을 참고로 첨부하고 요청 7-1의 병종 문장·공통 문장으로 새로 생성했다. 앞-오른쪽 자세와 무기 든 손을 유지했다. 방패/활/창은 화면 오른쪽, 방패병 검과 기병의 든 칼은 화면 왼쪽, 말의 머리는 오른쪽이다. 좌우 반전하지 않았다. 망자군 방패·투구·마구에는 나라 문장을 넣지 않았고 부적에는 추상 무늬만 있다. 방패·궁병·기병은 해골, 창병은 창백하고 금 간 피부의 망자다. 피·살점은 없다.

배경은 RGBA 투명이며 부드러운 가장자리와 작은 보라 연기의 부분 알파를 유지했다. 별도의 바닥이나 그림자를 넣지 않았다. 생성 원본의 전체 캔버스를 잘라내지 않고 비율을 유지해 원본 병사와 같은 캔버스에 LANCZOS 축소했다. 이번 병사 그림은 셀 셰이딩이므로 전장 배경에 쓰던 40색·4×4 도트 정리는 적용하지 않았다.

네 장을 원본과 같은 크기로 나란히 놓고 자세·장비·발/말발굽 잘림·투명 합성을 확인했다. 약 50px 높이의 미리보기에서도 네 병종을 비교했다. PNG 형식·크기·투명 알파·윤곽 여백 검사와 Chromium의 4파일 로딩/디코딩 검사를 통과했다. 이는 게임 실기 검수가 아니다. 기존 `index.html`·아군 4병종 그림·방향/걷기 에셋은 수정하지 않았다.

Claude는 사용자 확인 후 귀왕 적 병사에만 진영색을 덧입히지 않고 연결한다. 다른 진영 적·장수는 기존 그림을 유지하고, 연결 시 표시 높이 49.4 기준으로 머리 크기·발 위치·기병 말발굽을 모바일 세로/가로에서 확인한다. 아직 없는 방향/걷기는 기존 대체 동작을 사용한다.
