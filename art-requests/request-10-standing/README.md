# 요청 10 · 20명 정지 4방향

사용자가 이번 대화에서 지정한 최종 범위는 20명 각각 fr/fl/br/bl 정지 이미지다. 첨부 브리프의 걷기 시트 단계는 사용자 지시로 취소되었다. 원본 방향도 같은 스타일로 새로 생성했다. 방향마다 이미지 생성 도구를 사용했으며 좌우 반전 변환으로 만들지 않았다. 생성 중 발견한 방향 오류는 재생성했다.

## 파일

- `<name>/<name>-<dir>.png`: 투명 RGBA 생성 원본 80장, 각 1254×1254.
- `index.html`: 원본을 캐릭터별 네 방향으로 비교하는 로컬 HTML 목록.
- `manifest.json`: 파일명, 실제 크기, 알파 범위, 불투명 영역, SHA-256, 요청 규격.
- `source/`: 사용자가 첨부한 수정 참고 ZIP과 원문 브리프. 원문 브리프의 과거 범위보다 이번 사용자 지시가 우선한다.

## 검증과 남은 작업

20명 × 4방향 = 80개 파일, 80개 고유 해시, 모두 RGBA 및 투명 픽셀 존재, 누락 없음. 이 검사는 색상·얼굴·해부학적 손 일치의 자동 검증을 의미하지 않는다. 게임의 기존 에셋과 소스에는 연결하지 않았다.

요청 출력 규격은 보병 256×256, 기병 384×384다. 수정 참고 ZIP을 확인하면 호연·사율뿐 아니라 비연도 기병이다. 현재 파일은 생성 도구가 반환한 고해상도 원본이며 규격 출력 및 캐릭터별 발 기준점 정렬은 아직 완료하지 않았다. 원본을 보존하고 별도 도구로 규격본을 추가 출력하는 단계에 대한 사용자 답변을 기다린다. 완성된 게임용 규격 에셋이라고 간주하지 않는다.

각 캐릭터 완료 때 `art/request-10-standing-20` 브랜치에 커밋·푸시했다. `main`에는 병합하지 않았다.
