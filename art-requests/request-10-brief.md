# Art brief · 20 leaders · 45° four-direction + walk cycle (request 10)

You are making game art for a Korean fantasy strategy game. Each attached image is the ONLY existing picture of a character (a cute chibi anime illustration). The battle map needs each character from four 45-degree directions and a walking animation. Follow every rule below for every image.

## Style rules (apply to every image)
- Exactly the same character as the reference: same face, hairstyle, outfit, armor, weapon, colors and cute chibi SD (2–3 heads tall) proportions.
- **Keep the reference colors exactly.** The references are already in each nation's color: Azure Dragon (Cheongmyeong, Unhak, Dansim, Mukcheol) = blue clothes, Black Tortoise (Seojin, Seolhwa, Yeonbaek, Dogyeom) = dark navy/black clothes, White Tiger (Ganghyeon, Hoyeon, Eunrang, Sayul) = white clothes, Vermilion Bird (Yeonhwa, Biyeon, Hongyeom, Haerin) = red clothes. Ghost King side (Gwiwang, Heukcheol, Mujin, Baekryun) keeps its own colors. Every new direction and walk frame must use the same clothing colors as its reference. The nation list is only a hint; when in doubt copy the reference (e.g. Hoyeon keeps brown leather armor with a white cape).
- Anime illustration, clean dark-brown outlines, soft cel shading, bright colors. NOT pixel art, NOT photo, NOT 3D.
- 45-degree diagonal view, seen slightly from above (isometric game camera), same as the reference.
- Never mirror the character: the weapon stays in the same hand as in the reference.
- Full body, nothing cropped (feet / hooves visible). One character only (a rider includes the whole horse, which faces the same way).
- Transparent background (if impossible: plain white). No shadow, no ground, no text, no frame.
- Keep the standing height the same as the reference.

## Directions
- **fr** = facing the viewer's RIGHT: front three-quarter view, face and chest visible, looking toward the lower right.
- **fl** = facing the viewer's LEFT: front three-quarter view, face and chest visible, looking toward the lower left.
- **br** = seen from behind, body turned away toward the upper RIGHT, back of the head visible.
- **bl** = seen from behind, body turned away toward the upper LEFT, back of the head visible.

## Stage 2 · walk cycle sheets (80 images)
For each character and each of the 4 directions (fr, fl, br, bl — including the reference direction), draw ONE sheet with 4 poses side by side in equal cells, left to right: right foot forward, feet together, left foot forward, feet together. Same size, same ground line and same head height in every cell. A rider's horse walks with its four legs.
Save as `<name>-<dir>-walk.png`, e.g. `seolhwa-bl-walk.png`.

## Order of work
Finish one character completely (stage 1 then stage 2) before the next, so the face and outfit stay consistent. After each image, check: same character, correct direction, weapon in the same hand, full body, transparent background. Redo if any check fails.
